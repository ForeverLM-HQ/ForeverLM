# The preference-key ratchet (scripts/check_preference_keys.sh, PreferenceKeyLiteralTests).
#
# One line per Swift file that still reaches defaults by a string key or spells a
# declared preference key: the number of such lines, a tab, the path from ForeverLMApp.
# A file may have that many and no more; a file that is not listed may have none.
# The numbers only go down. When a file moves to typed keys (`Prefs`), lower its line
# or delete it: `sh scripts/check_preference_keys.sh --update` rewrites the list from
# today's counts.
#
# The files that are the typed layer's own plumbing stay listed for good:
# PreferenceStore, SyncedStorage, PreferenceStorage, DefaultsEscapeHatch,
# SyncedPreferenceKeys, RetiredDefaultsCleanup, LegacyIdentityAdoption, and the
# app-group suites of the widget and the share sheet.
