# Code of Conduct

ForeverLM follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, argue about the code and not the person, and assume the
other side means well. Harassment, personal attacks and publishing someone's
private information are not accepted in issues, pull requests or any other
project space.

Report a problem to **support@foreverlm.com**. Reports are kept confidential.
