# ForeverLM vs Papers (ReadCube)

Papers is a mature reference manager for discovering, organizing, annotating, sharing, and citing academic literature. Its AI Assistant can explain one PDF or find themes across a set of papers. ForeverLM also manages papers and chats across them, but puts those papers beside articles, books, podcasts, videos, and courses in a library designed for learning.

Papers moves research from **search to citation**. ForeverLM moves sources from **capture to understanding**.

## At a glance

| | ForeverLM | Papers |
|---|---|---|
| **Price** | Free; MCP is 30 days free, then $19 once (no subscription); AI on your own OpenRouter key at cost | Essentials $65/year; Pro $130/year; 40% academic discount |
| **Library** | Papers plus articles, books, podcasts, videos, courses, meetings, and more | Academic references and research files |
| **AI** | Chat with any selected sources or the wider library using configurable models and MCP assistants | Chat with one PDF on Essentials; up to 20 papers and AI search on Pro |
| **Citations** | Stores scholarly metadata, but no cite-while-you-write plugin | SmartCite for Word and Google Docs, with 10,000+ styles |
| **Listening** | Reads papers aloud and keeps audio attached to the source | No comparable paper-listening workflow |
| **Review** | Schedule sources and save review history | No source-linked active-review system |
| **Platforms** | Mac-centered, with synced iPhone access | Web, desktop, iOS, and Android |

*Papers pricing and features checked against its [official pricing page](https://www.papersapp.com/pricing/) in August 2026.*

## Where Papers is better

- **Reference management.** Papers is purpose-built for bibliographies, metadata repair, related-paper discovery, shared libraries, and academic collaboration.
- **Cite while you write.** SmartCite inserts and formats citations directly in Word and Google Docs.
- **Research discovery.** Pro searches more than 150 million publications through Dimensions and turns natural-language requests into structured searches.
- **Cross-platform access.** Researchers can work across Windows, macOS, the web, iOS, and Android.
- **Team workflows.** Shared libraries, transferable seats, permissions, and institutional plans serve labs better than ForeverLM does today.

## Where ForeverLM is more complete

- **Research is not limited to papers.** A literature notebook can include the authors' podcast interviews, conference talks, books, articles, and meeting notes.
- **AI can operate the library.** An MCP assistant can search sources, retrieve content, organize notebooks, manage a learning schedule, and save a review transcript back to ForeverLM.
- **Listening is integrated.** Read a dense paper aloud, pause to ask questions, and continue without creating a detached audio file.
- **Understanding is recorded.** Scheduling, completion state, and reviews turn reading into a repeatable learning loop.
- **No annual research-software fee.** The library is free, instead of an annual tier; only using it from Claude or ChatGPT over MCP is paid, $19 once after 30 free days. The built-in AI runs on your own OpenRouter key: pay models at cost, or use free models.

## Which should you choose?

Choose **Papers** if you need a professional reference manager, cite-while-you-write tools, research discovery, and collaboration across a lab.

Choose **ForeverLM** if you want papers integrated with every other source you learn from, with listening, cross-source conversation, scheduling, and active review.

They work well together: keep a canonical citation library in Papers, then bring the papers you are actively learning into ForeverLM.
