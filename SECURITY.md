# Security

## Reporting a vulnerability

Email **security@foreverlm.com**. Please do not open a public issue for a
vulnerability.

Include what you found, how to reproduce it, and the app version and build
(ForeverLM › About). You will get a reply acknowledging the report, and we will
tell you when a fix ships.

## Scope

- The ForeverLM apps for Mac, iPhone and iPad, and the code in this repository.
- The in-app MCP server and its OAuth flow.

A learner's library lives in their own iCloud, and model calls go out with the
learner's own OpenRouter key. A report that shows either of those reaching
someone it should not is in scope and treated as urgent.

## Supported versions

Only the latest released version receives security fixes.
